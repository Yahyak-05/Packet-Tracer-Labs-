# Packet Tracer Labs

Daily labs designed to fully understand and master network topologies using Cisco Packet Tracer. These exercises provide hands-on experience with detailed network configuration, including VLANs, trunking, inter-VLAN routing, IP addressing, subnetting, routing protocols, Spanning Tree Protocol (STP), and other essential networking concepts. Each lab is completed in sequence to build a strong foundation in network design, configuration, troubleshooting, and practical Cisco networking skills.
